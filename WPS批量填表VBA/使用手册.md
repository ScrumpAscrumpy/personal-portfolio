## 1. 工具原理

工具有两种填写方式，**自动按文档情况选择**：

### 主方式：占位符替换（推荐，最可靠）

目标 Word 文档里凡是要填的位置，都写上 `{{字段名}}` 标记。工具会把它精确替换为数据源里对应的内容。

```
目标文档（模板）              数据源.docx
┌──────┬──────────────┐      ┌──────────┬──────────────┐
│ 姓名 │ {{姓名}}     │      │ 字段名   │ 填写内容     │
│ 性别 │ {{性别}}     │  +   ├──────────┼──────────────┤
│ 手机 │ {{手机号}}   │      │ 姓名     │ 张三         │
└──────┴──────────────┘      │ 性别     │ 男           │
         ↓ 运行宏             │ 手机号   │ 13800138000  │
┌──────┬──────────────┐      └──────────┴──────────────┘
│ 姓名 │ 张三         │
│ 性别 │ 男           │   ← {{}} 被替换为实际内容
│ 手机 │ 13800138000  │
└──────┴──────────────┘
```

**优点**：精确、不会误填、不受合并单元格影响、同一字段可在文档多处重复使用（如 `{{姓名}}` 出现多次会全部填上）。你上传的《广东省企业职工基本养老保险待遇申报表》就是这种模板。

### 备用方式：智能识别空白格

如果目标文档**没有** `{{}}` 标记，工具会自动扫描表格，找"标签格 → 相邻空白格"，把数据源里同名字段填进去。适合没有标记的普通表格。

## 2. 安装步骤（首次使用）

### 第一步：打开 WPS 宏编辑器

1. 打开 WPS Office（文字 / Writer）
2. 菜单栏 **「工具」→「宏」→「WPS宏编辑器」**（或按 `Alt + F11`）

> 若菜单里没有「宏」，先启用：**「设置」→「信任中心」→「宏设置」→ 启用所有宏**

### 第二步：导入 .bas 模块文件

1. 宏编辑器左侧「工程」面板，右键点击 `Normal`
2. 选择 **「导入文件」**
3. 选择 `批量填表工具.bas`
4. 左侧出现「**批量填表工具**」模块即成功

### 第三步：验证安装

回 WPS 主界面 → **「工具」→「宏」→「运行宏」**，能看到这三个宏即成功：

- `批量填写Word文档` ← 主功能
- `创建数据源模板` ← 生成数据源模板

## 3. 准备数据源文档

数据源是一个 Word 文档，含一个**两列表格**：

| 字段名（对应占位符，不含大括号） | 填写内容 |
|----------------------------------|----------|
| 姓名                             | 张三     |
| 性别                             | 男       |
| 户籍省市                         | 广东省广州市 |
| 户籍地址                         | 广州市天河区天河路100号 |
| 手机号                           | 13800138000 |
| 身份证号码                       | 440101196003151234 |
| 最后缴费年月                     | 2020年3月 |
| 开户银行                         | 中国银行广州分行 |
| 社保卡号                         | 6217001234567890 |
| 家属名字                         | 李四     |
| 家属身份证号                     | 440101196505201234 |
| 家属电话                         | 13900139000 |

### 快速生成模板

运行宏 **「创建数据源模板」**，工具会自动生成一份含你那张养老保险表所有字段的模板，你只需在右列填值即可。

> **关键**：左列字段名要和目标文档里 `{{}}` 中的名字**完全一致**。
> 例：目标文档写 `{{手机号}}`，数据源左列就要写 `手机号`（不带大括号）。

## 4. 给目标文档加占位符

如果你的目标 Word 文档还没有 `{{}}` 标记，按以下方式添加（**每个模板只需做一次**）：

1. 打开目标 Word 文档
2. 在每个要填写的空白处，输入 `{{字段名}}`
   - 姓名栏 → 输入 `{{姓名}}`
   - 手机栏 → 输入 `{{手机号}}`
3. 保存

之后这个文档就成了可重复使用的模板，每次换数据源就能填出不同的人。

> 你上传的养老保险表**已经标好了占位符**，可直接使用，无需再标。

## 5. 批量填写操作流程

运行宏 **「批量填写Word文档」**，按提示三步走：

```
第一步：选择数据源文档
        → 选你填好内容的"数据源.docx"

第二步：选择目标 Word 文档（可多选）
        → 按住 Ctrl 点击多个模板文档，点"打开"

第三步：选择输出目录
        → 选填好后的新文档存放位置

自动处理中…（每个文档几秒）

完成！弹出结果报告，自动打开输出文件夹
```

输出文件命名：`原文件名_已填写_20260613_150700.docx`
（原始模板**不会被修改**，工具先复制副本再填写）

## 6. 两种填写模式说明

工具对每个目标文档，**先做占位符替换，再做智能识别**，两者叠加：

| 场景 | 工具行为 |
|------|----------|
| 文档含 `{{字段名}}` | 精确替换为数据源对应值（主方式）|
| 文档无标记、是标签表格 | 扫描"标签→空白格"自动填（备用方式）|
| 同一占位符出现多次 | 全部替换（如 `{{姓名}}` 在开户名、家属栏都用）|
| 数据源没有的字段 | 保持原样不动 |
| 值为空的字段 | 占位符被清空（删除 `{{}}` 标记）|

### 智能识别的规则（仅备用方式用到）

- 标签长度 1–16 字
- 标签不含复选框符号 □ ■ ●
- 紧邻右侧格为空，或仅含 "年 月 日" / "省 市" 等格式提示

## 7. 常见问题

**Q：运行宏提示"宏被禁用"？**
A：WPS 设置 → 信任中心 → 宏设置 → 改"启用所有宏"，重开 WPS。

**Q：占位符没被替换？**
A：检查数据源左列字段名和文档里 `{{}}` 中的名字是否**完全一致**（含全角/半角、有无空格）。例如 `{{ 姓名 }}`（带空格）和数据源 `姓名` 不匹配。

**Q：`{{}}` 被打散到不同格式（一半加粗一半不加粗），还能替换吗？**
A：能。工具用 WPS 的查找替换引擎，能跨文字片段匹配整个占位符。

**Q：目标文档有大量合并单元格，会出错吗？**
A：不会。占位符替换不依赖单元格结构；备用的智能识别也内置了合并单元格去重逻辑。

**Q：可以一次填几十份文档吗？**
A：可以，多选无数量限制，逐个处理。

**Q：原始模板会被改吗？**
A：**不会**。工具先把模板复制到输出目录，只对副本写入。

**Q：macOS 上能用吗？**
A：能。代码已做跨平台处理（路径分隔符、打开文件夹命令自动适配）。
