## 1. 工具原理

```
数据源.docx              目标表格1.docx
┌──────────┬──────────┐  ┌────────┬─────────────────┐
│ 字段名   │ 填写内容 │  │ 姓名   │ ← 自动写入"张三" │
├──────────┼──────────┤  ├────────┼─────────────────┤
│ 姓名     │ 张三     │  │ 性别   │ ← 自动写入"男"  │
│ 性别     │ 男       │  └────────┴─────────────────┘
│ 身份证号 │ 110...   │
└──────────┴──────────┘  目标表格2.docx
          ↓              ┌────────┬───────┐
     宏自动填写           │ 姓名   │ 张三  │
                         │ 身份证 │ 110...│
                         └────────┴───────┘
```

工具会扫描目标 Word 文档里所有表格，找到与数据源字段名**完全匹配**的标签格，把对应内容写入紧邻的空白格。不匹配的格子保持不变，**不会修改原始文档**（输出为新文件）。

## 2. 安装步骤（首次使用）

### 第一步：打开 WPS 宏编辑器

1. 打开 WPS Office（文字/Writer）
2. 菜单栏点击 **「工具」→「宏」→「WPS宏编辑器」**  
   （或按快捷键 `Alt + F11`）

> 如果菜单里没有「宏」，需要先在 WPS 设置中启用开发者功能：  
> **「设置」→「信任中心」→「宏设置」→ 选择"启用所有宏"**

### 第二步：导入 .bas 模块文件

1. 在宏编辑器左侧「工程」面板，右键点击 `Normal`（或你的文档名）
2. 选择 **「导入文件」**
3. 找到并选择 `批量填表工具.bas` 文件
4. 导入后左侧面板会出现「**批量填表工具**」模块

### 第三步：验证安装

回到 WPS 主界面，点击 **「工具」→「宏」→「运行宏」**，  
在列表中能看到以下三个宏说明安装成功：

- `批量填写Word文档` ← 主功能
- `创建数据源模板` ← 首次使用时生成模板

## 3. 准备数据源文档

数据源是一个普通 Word 文档，里面有一个**两列表格**：

| 字段名（与表格标签一致） | 填写内容 |
|--------------------------|----------|
| 姓名                     | 张三     |
| 性别                     | 男       |
| 出生日期                 | 1958年3月15日 |
| 身份证号                 | 110101195803151234 |
| 联系电话                 | 13800138000 |
| 工作单位                 | 北京市第一机械厂 |
| …                        | …        |

### 方法一：用工具自动生成模板（推荐）

1. 运行宏 **「创建数据源模板」**
2. 选择保存位置，工具自动创建含常用字段的模板
3. 打开模板，在**右列**填入你的信息
4. 保存

### 方法二：自己新建

新建 Word 文档 → 插入一个两列表格 → 左列写字段名，右列写内容。

> **注意**：左列字段名必须和目标 Word 文档里的标签**完全一致**，包括全角/半角、有无空格。

## 4. 批量填写操作流程

运行宏 **「批量填写Word文档」**，按提示操作：

```
第一步：选择数据源文档
        ↓ 弹出文件选择框
        选择你填好内容的"数据源.docx"

第二步：选择目标 Word 文档（可多选）
        ↓ 弹出文件选择框
        按住 Ctrl 点击多个要填写的文档，点"打开"

第三步：选择输出目录
        ↓ 弹出文件夹选择框
        选择填好后的文档存放位置

自动处理中…（每个文档几秒钟）

完成！弹出结果报告，自动打开输出文件夹
```

输出文件命名格式：`原文件名_已填写_20260613_143022.docx`

## 5. 字段名匹配规则

工具按以下规则识别目标文档里的"标签格"：

| 规则 | 说明 |
|------|------|
| **长度 1-16 字** | 超过 16 字的格子被认为是正文，不是标签 |
| **不含复选框符号** | 含 □ ■ ● 的格子跳过（避免误填选项） |
| **紧邻的右侧格为空** | 或仅含日期/地址提示（如"年  月  日"、"省  市"） |
| **同一标签只填一次** | 避免重复覆盖 |

### 如果某个字段没有被填写，检查：

1. **字段名拼写**：数据源左列和目标文档标签是否完全一致？
   - 错误示例：数据源写 `"姓 名"`（有空格），目标文档是 `"姓名"`
   - 解决：统一去掉多余空格
   
2. **标签后的格子是否为空**：如果标签右边的格子已有内容（如说明文字），工具不会覆盖
   
3. **标签长度**：超过 16 个字符的标签会被跳过（工具认为它是正文段落）

## 6. 常见问题

**Q：运行宏时提示"宏被禁用"怎么办？**  
A：WPS 设置 → 信任中心 → 宏设置 → 改为"启用所有宏"，然后关闭重开 WPS。

**Q：数据源的两列表格，但有些字段读取不到？**  
A：确保每行只有两列（或前两列是字段名和值），表格不能有合并单元格的首行。

**Q：目标文档的表格有很多合并单元格，会不会出错？**  
A：不会。工具内置了合并单元格去重逻辑（与 Python 版本相同算法），会正确处理。

**Q：可以同时填写几十个文档吗？**  
A：可以，批量选择没有数量限制，工具按顺序逐个处理。

**Q：原始文档会被修改吗？**  
A：**不会**。工具会先把原始文档复制一份到输出目录，然后只对副本进行写入。原始文档完全不动。

**Q：macOS 上 WPS 可以用吗？**  
A：可以，代码已做跨平台处理（自动识别路径分隔符和文件夹打开命令）。

**Q：WPS 宏编辑器找不到"导入文件"选项？**  
A：右键点击工程面板里的**「模块」文件夹**（不是根节点），再选「导入文件」。  
或者：在编辑器菜单栏选「文件」→「导入文件」。
